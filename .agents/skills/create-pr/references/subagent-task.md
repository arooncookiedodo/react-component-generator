# PR 실행 서브 에이전트 작업 계약

주 에이전트는 PR 실행 서브 에이전트 하나에게 다음과 동등한 작업을 전달한다. 확인된 값만 채우며, 알 수 없는 정보를 임의로 만들지 않는다.

```text
PR 실행 서브 에이전트로 작업한다. 저장소 <저장소 절대 경로>에서
<.agents/skills/create-pr의 절대 경로>에 있는 create-pr 스킬을 실행한다.

사용자 요청: <원문 요청>
확인된 맥락: <브랜치/대상 브랜치/검증 정보 또는 "아직 확인된 정보 없음">.

스킬의 PR 실행 서브 에이전트 워크플로를 직접 수행한다. 다른 서브 에이전트를
생성하지 않는다. 스킬의 결과 계약에 맞춰 주 에이전트에 결과를 반환한다.
```

작업은 사용자의 승인 범위를 유지해야 한다. 실행자는 사전 점검에 필요한 저장소와 호스팅 상태를 확인할 수 있지만, 승인되지 않은 커밋, 푸시, 언어 선택 또는 기타 중요한 작업이 있어야 생성할 수 있다면 중단하고 차단 사유를 반환한다.
